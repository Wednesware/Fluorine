# Changelog

## 26.7

- Add `Page.render()` for HTML generation without writing a file.
- Add a read-only `Page.callbacks` registry with stable public callback names,
  including deduplication of repeatedly accessed bound methods.
- Generate an optional Promise-based callback helper that waits for a host,
  reports missing callbacks, and explains when Python is unavailable.
- Support `Page.attach_runtime()` and `detach_runtime()` while retaining the
  previous `_attach_window()` hook for compatibility.
- Add `Element.replace()` and live event rebinding; normalize `click` to
  `onclick` in `bind()`.
- Correct live boolean attributes and add `aria_`/`data_` attribute shorthands.
- Create output directories automatically and write HTML as UTF-8.
- Add regression tests and clean Nitrogen-compatible release archives.

Python callbacks still require a running Python host. Static HTML, CSS, and
JavaScript remain usable independently. Callback names generated by 26.7 differ
from 26.6; regenerate HTML and use its matching callback registry together.
